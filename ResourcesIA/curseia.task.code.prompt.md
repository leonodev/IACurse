## Code Guidelines
- me debes preguntar como se llama la funcionalidad que vamos a trabajar, yo te respondere y tu tendras este nombre en cuenta para el paso siguiente.
- create una rama que se llame "feature/nombre-de-la-funcionalidad".
- No usea Combine, en su lugar siempre usaremos Async/Await.
- los componentes de UI que te indique que debes crear, todos deben tener internamente el manejo de estos 4 estados: 
    - skeleton: para mostrar un placeholder mientras se carga la información.
    - error: para mostrar un mensaje de error cuando la información no se ha podido cargar.
    - disabled: para mostrar el componente en un estado deshabilitado, sin interacción.
    - normal: para mostrar el componente en su estado normal, con toda la información cargada y con interacción habilitada.
